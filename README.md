# NusaWeb — Ujian Praktik Landing Page TJKT

Bidang: jasa pembuatan website dan hosting. Perusahaan, alamat, portofolio, dan harga merupakan ilustrasi untuk tugas sekolah.

## Menjalankan

Buka `index.html` di browser. Tidak perlu instalasi atau build. File HTML, CSS, JavaScript, dan gambar berada di folder ini. Font Google memerlukan internet; font cadangan tetap tersedia saat offline.

## Sebelum dikumpulkan

- WhatsApp sudah dipasang: 089665831166 (format internasional 6289665831166). Semua tombol konsultasi dan paket memakai nomor tersebut.
- Periksa di laptop dan smartphone, termasuk menu navigasi, tombol WhatsApp, dan gambar.
- Persyaratan penggunaan Antigravity belum dilakukan oleh pembuat kode ini. Jalankan prompt pada `PROMPT-ANTIGRAVITY.txt` melalui Antigravity untuk menghasilkan kerangka awal dan simpan bukti proses. Gunakan file proyek ini sebagai referensi modifikasi manual, mengikuti ketentuan guru. Jangan mengklaim kerangka ini dibuat di Antigravity.

## Struktur

- `index.html`: header, hero, 3 layanan, 2 konsep portofolio dengan detail yang bisa dibuka di halaman yang sama, 3 keunggulan, paket, kontak, dan footer beralamat fiktif Surakarta.
- `style.css`: tampilan, hover tombol, fokus keyboard, dan responsivitas.
- `script.js`: menu seluler dan link WhatsApp dengan pesan otomatis.
- `assets/`: foto lokal dari Unsplash; sumber tercantum di `assets/SOURCES.txt`.

## Penyesuaian UMKM

Fokus layanan: landing page satu halaman, menu digital, dan katalog sederhana. Hemat Rp150.000; Menu & Katalog Rp250.000; Update Ringan Rp25.000 per permintaan, maksimal 5 item. Setup hosting statis gratis menggunakan subdomain bawaan sesuai batas penyedia; domain sendiri opsional dan dibayar terpisah.

Yang masih perlu disesuaikan jika dipakai untuk usaha nyata: merek NusaWeb (opsional), alamat fiktif, serta contoh portofolio dengan karya sendiri. Untuk ujian, alamat fiktif dan portofolio berlabel konsep bisa dipertahankan. Bukti penggunaan Antigravity tetap perlu dibuat.

## Perbaikan keterbacaan dan contoh

Hero menggunakan konsep Warung Bu Sari dengan foto makanan. Detail portofolio dibuka langsung melalui elemen details/summary di halaman utama, tanpa halaman terpisah. Semua usaha, menu, harga, dan jadwal pada detail portofolio adalah ilustrasi, dan link konsultasi mengarah ke bagian kontak NusaWeb. Teks informasi utama minimal 14px; label mockup 12px. Waktu pengerjaan dibicarakan setelah bahan diperiksa.

Website hanya memiliki satu halaman HTML: index.html. Detail contoh portofolio tetap berada di halaman yang sama dan bisa dibuka tanpa JavaScript.
